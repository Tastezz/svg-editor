## 完成后你要能演示什么

CLI 已可执行。你回来后可以按下面顺序亲自验收；我的测试不代替你的实际理解和演示。

1. 在 `~/Projects/svg-editor` 用 `npm ci`、`npm run typecheck`、`npm test` 检查工程。
2. 用 `npm run cli` 创建“矩形＋文字”的嵌套节点，移动整个容器，撤销并重做。
3. 尝试重复 id、非法分组和错误缩放，说明为什么失败不会改变文档和历史。
4. 保存 SVG 并在浏览器查看；解释成功保存之后为什么不能直接 undo。
5. 指出 CommandDispatcher 与 ShapeFactory 两处分派位置，说明未来插件化会改哪里。
