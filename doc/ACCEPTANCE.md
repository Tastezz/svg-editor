## 历史与原子性重点序列

- [ ] create → move → undo → redo：位置精确恢复，不依赖反向浮点误差。
- [ ] 编辑 A → undo → 显示/查询 → redo：redo 仍可用。
- [ ] 编辑 A → undo → 失败编辑 → redo：redo 仍可用。
- [ ] 编辑 A → undo → 成功编辑 B → redo：原分支不可再重做。
- [ ] 编辑 → 成功 save → undo/redo：两者均报 undo not allowed after io command。
- [ ] 屏障后 → 失败编辑 → undo：仍受屏障限制。
- [ ] 屏障后 → 成功编辑 → undo：只撤销新编辑，不跨越 I/O。
- [ ] 编辑 → canvas 查询/失败 save/失败 read → undo：仍能撤销原编辑。
- [ ] 多次 group/addto/delete/ungroup 后逐次撤销与重做：父子关系、id 索引和顺序均与预期一致。
- [ ] 每类失败对比前后模型、路径和历史，确认完全未变；失败写文件不破坏原目标。
